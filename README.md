a chiptune DAW built from scratch with [zig](https://ziglang.org/) and [sokol](https://github.com/floooh/sokol) 

- built with chiptune in mind
- cute pixel UI
- small footprint
- synth can be built independently and embedded in other programs
- currently a work in progress, but growing...!

## building

- install [zig](https://ziglang.org/download/)
- run `zig build run` from the repo root
